わたしの美術館 — アプリとして設置する手順
==========================================

このフォルダ一式を、https で開ける場所に置くと、
スマホのホーム画面に追加して単体アプリとして使えます。

■ 置き場所（どれかひとつ）
  ・GitHub Pages      : リポジトリを作り、この一式を置いて Settings → Pages を有効化
  ・Netlify Drop      : https://app.netlify.com/drop にこのフォルダをそのままドラッグ
  ・Cloudflare Pages  : ダッシュボードからフォルダをアップロード
  ※ Webサーバーが必要な理由は2つ。ホーム画面への追加がhttpsを要求するため、
     サービスワーカー（オフライン起動）が https か localhost でしか動かないためです。

■ 追加のしかた
  Android / Chrome : 画面下に出る「インストール」、または設定と保管 →「ホーム画面に追加」
  iPhone / Safari  : 共有ボタン →「ホーム画面に追加」

■ ファイル構成
  index.html             アプリ本体（この1枚で動きます）
  manifest.webmanifest   アプリ名・アイコン・ショートカットの定義
  sw.js                  サービスワーカー（オフライン起動と更新）
  icons/                 アイコン各種

■ 保存先について
  記録は端末内（IndexedDB）に保存されます。複数端末で同じ美術館を見るには、
  設定と保管 → Googleドライブと同期する、からご自身のクライアントIDで接続してください。
