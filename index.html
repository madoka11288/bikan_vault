新しいサービスの登録もOAuthの設定も不要で、非公開リポジトリに保管できます。サイトのURLが公開でも、保存したものは誰にも見えません。
GitHub同期の準備（5分）
  1. GitHubで非公開の新規リポジトリを作る（例：bikan-vault）。Add README をONにしてブランチを作ってください
  2. Fine-grained token を作成
  3. Repository access は「Only select repositories」でそのリポジトリだけを選ぶ
  4. Permissions → Repository permissions → Contents を Read and write にする（他は触らない）
  5. 有効期限を決めて Generate し、github_pat_… をここに貼る
Nextcloudは「設定 → セキュリティ → アプリパスワード」で発行できます。ブラウザから別サーバーへ直接つなぐため、サーバー側でクロスオリジンの許可（CORS）が必要です。許可できない場合は同じドメインにアプリを置くか、GitHubをお使いください。
ご自身のGoogle Cloudプロジェクトで発行したIDが必要です。承認済みのJavaScript生成元には、アプリのURLのドメインまでを登録してください（パスは入れません）。
Googleドライブ同期の準備
  1. Google Cloud で Google Drive API を有効化
  2. OAuth同意画面を作成（テストユーザーに自分のアドレスを追加）
  3. 認証情報 → OAuthクライアントID → 種類はウェブアプリケーション
  4. 「承認済みの JavaScript 生成元」にアプリのURLのドメインを追加
  5. 発行されたIDをここに貼り付けて「接続して確認」
未接続 — この端末の中だけに保存されています
